指针实验最开始做的事情很简单：定义一个变量，输出它的值和地址，再通过指针修改它。真正困难的地方，是看到 `&` 和 `*` 时，脑子里还没有形成稳定的对应关系。

```c
int value = 7;
int *p = &value;
*p = 9;
```

在这个例子里，`value` 是整数对象，`&value` 是它的地址，`p` 保存这个地址，`*p` 表示通过地址访问那个整数。最后变化的是 `value` 的值，指针仍然指向同一个对象。

## 两种改变要分清

`p = &other` 改变指向，`*p = 10` 改变所指对象的值。画两个小方框和一根箭头，比只背“间接寻址”四个字更有帮助。

打印地址时，可以用 `printf("%p", (void *)p)`。地址的具体数字并不重要，重要的是哪些指针指向同一个对象，以及这个对象是否仍然存在。

## 类型不能随意混用

旧实验材料里有把整型对象和浮点型指针混在一起的练习描述。整理这部分时需要特别小心：不能为了看到一个结果，就把 `int` 的地址强行当成 `float *` 去解引用。表示方式和访问规则不同，偶然输出一个数字不代表写法正确。

指针算术也和类型有关。指向整数数组元素的指针加一，移动的是一个整数元素的距离，并不是固定移动一个字节。

## 每次解引用前都值得想一下

它有没有初始化？指向的对象还在不在？这个位置是否在合法范围内？这些问题看起来啰嗦，却能把“怎么有时能跑、有时不能跑”变成具体可查的原因。指针需要的第一种熟练，是先把对象关系讲明白。
