# 从一大段 main 到几个能讲清楚的函数

函数实验里有最大公约数、排序、字符串处理、阶乘和矩阵转置。把所有内容塞进 `main` 当然也能开始写，但题目一多，输入、计算、输出就容易纠缠在一起。

## 一个函数先做一件事

以最大公约数为例，函数只负责计算，不顺手读取键盘，也不负责决定输出格式。下面约定输入为非负整数：

```c
int gcd(int a, int b) {
    while (b != 0) {
        int remainder = a % b;
        a = b;
        b = remainder;
    }
    return a;
}
```

主函数读取数据，再调用它，最后显示结果。这样检查 `gcd(12, 18)` 时，可以只关心结果是不是 6。若还要求最小公倍数，要单独处理零，并注意乘法的数值范围。

## 参数传进去的是怎样的东西

交换变量是很好的提醒。`swap(int a, int b)` 里交换的是形参的副本，不会自动改变调用者的两个变量。需要修改外部变量时，应明确传入地址，并通过指针写回；调用前也要保证指针有效。

这也说明函数签名不只是一个格式。它在告诉使用者：我要什么输入，会不会修改你的数据，会返回什么结果。哪怕只有十几行，也值得把这三件事说清楚。

## 拆分以后更容易复查

数组处理可以拆成输入、计算、输出三个步骤。出现错误时就能先判断：数据读错了，计算错了，还是只是显示错了。拆分的目的不是让函数越多越好，而是让一段逻辑能单独说明、单独检查。

从这一步开始，程序不再只是“写到能跑”，也开始有了可以重新阅读的结构。
