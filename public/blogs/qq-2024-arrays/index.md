# 数组与字符串：给结束符留一个位置

数组实验把求和、矩阵转置、字符串反转和字符统计放在一起。题目看起来很多，背后的共同问题其实很朴素：一块空间有多大，哪些位置可以访问，什么时候应该停止。

## 数量和下标是两件事

有 10 个元素的数组，下标是 0 到 9。循环通常写成 `i < 10`。把最后一个条件写成 `i <= 10`，多出来的那一次访问可能不会立即报错，却已经越界了。

矩阵转置也要先说清楚维度。一个 `rows × cols` 的矩阵，转置后是 `cols × rows`，对应关系为 `b[j][i] = a[i][j]`。先用一个两行三列的小矩阵手算，比盯着两层循环更直观。

## 字符串要多考虑一个结束符

C 字符串末尾需要 `\0`。如果数组是 `char text[10]`，用 `%s` 读取时最多接收 9 个普通字符：

```c
char text[10];
if (scanf("%9s", text) == 1) {
    printf("%s\n", text);
}
```

旧实验记录里出现过“十个字符的数组配 `%10s`”的想法，整理时需要纠正：字段宽度不包含自动添加的结束符。要读带空格的一行，可以考虑 `fgets`，同时处理它可能保留的换行符，以及输入过长时的剩余内容。

## 反转不应把结束符也交换进去

反转字符串时，交换区间是第一个字符到最后一个有效字符。空串和单字符也应该能平稳经过。把这两个边界例子加入检查，往往比再试一串很长的英文更有效。

数组这一章给我留下的提醒是：写代码前先画出空间，很多看似随机的错误就有了明确的位置。
